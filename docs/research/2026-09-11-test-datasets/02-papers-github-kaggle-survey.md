## Analysis

Most "unit test dataset" candidates fail on one of three axes: **granularity** (whole-repo/whole-file, not standalone function+test — UniTSyn as released, CAT-LM, TestGenEval, SWE-bench/SWE-smith/SWE-Gym, BugsInPy), **test style** (I/O judges dressed as tests — TACO/APPS/CodeContests/LiveCodeBench/LeetCodeDataset), or **license** (NC terms blocking most SFT pipelines — TestGenEval, KodCode). Be especially skeptical of anything sourced from competitive-programming platforms: "test cases" there means stdin/stdout pairs checked by a judge harness, not pytest modules asserting on a function's return value — converting these to your target shape means synthesizing the pytest wrapper yourself, which is most of the work you were trying to avoid by using an existing dataset.

The two datasets that most directly match the target shape (standalone function + own pytest module) are **KodCode-V1** and **AceCode-87K**. KodCode is pytest-native but carries a **CC BY-NC 4.0** license, which is a hard blocker if the output model or its training data need to be commercially usable — this needs a decision from whoever owns licensing before further investment. AceCode-87K is MIT-licensed and closer to usable immediately, but ships as `test_cases: List[str]` (bare asserts) rather than pytest modules, and includes zero self-contained-function data separate from question metadata — some restructuring (wrap asserts as `test_x()` functions, decide what "the function" is from `question`+model completions) is required, and its questions may overlap contamination-sensitive benchmarks (source field needs auditing).

## Top 5 ranked

1. **KodCode-V1** — pytest-native, synthetic (safe vs. 2026-06-01 cutoff), largest immediately-usable slice, but NC license needs resolution.
2. **AceCode-87K** — MIT, right scale, needs asserts→pytest conversion and contamination audit of source questions.
3. **UniTSyn** — largest raw pool (2.7M pairs) but requires running their own mining pipeline against re-downloaded repos; real yield after standalone-function filtering unknown, treat as a research pipeline, not a ready file.
4. **The Stack v2 permissive-Python raw mining** — highest ceiling, but is effectively "build CAT-LM's/UniTSyn's pipeline yourself"; only worth it if #1-#3 fall short of 5,000 after filtering.
5. **CAT-LM's aligned corpus** — same idea as UniTSyn/Stack-v2 mining but file-level and older; lower priority than UniTSyn since UniTSyn already did the function-level extraction work (just needs re-running).

**Download first, in order:** (1) KodCode-V1 (fastest path to a large pytest-shaped pool, pending the license decision) and (2) AceCode-87K (fully permissive fallback that guarantees a usable MIT-licensed base even if KodCode's NC license is a dealbreaker).
